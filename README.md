# 📚 Gerenciador de Livros (Node.js + MySQL)

Um sistema completo de **CRUD** (Create, Read, Update, Delete) desenvolvido para gerenciar o acervo de uma biblioteca de forma simples e eficiente.

## 🚀 Funcionalidades
*   **Cadastro:** Adicione novos livros com título e quantidade de páginas.
*   **Listagem:** Visualize todos os livros salvos no banco de dados em tempo real.
*   **Detalhes:** Veja informações específicas de cada livro por ID.
*   **Edição:** Altere dados de livros já cadastrados.
*   **Exclusão:** Remova registros do sistema com um clique.

## 🛠️ Tecnologias Utilizadas
*   **Ambiente:** [Node.js](https://nodejs.org)
*   **Framework:** [Express](https://expressjs.com)
*   **Banco de Dados:** [MySQL](https://www.mysql.com) (usando Connection Pool)
*   **Template Engine:** [Handlebars](https://handlebarsjs.com)
*   **Ferramentas:** `nodemon`, `mysql` driver.
