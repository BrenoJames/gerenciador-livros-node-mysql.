# 📚 Gerenciador de Livros (Node.js + MySQL)

Um sistema de CRUD (Create, Read, Update, Delete) completo, desenvolvido para gerenciar o acervo de uma biblioteca de forma simples e eficiente.

## 🚀 Funcionalidades
*   **Cadastro:** Adicione novos livros com título e quantidade de páginas.
*   **Listagem:** Visualize todos os livros salvos no banco de dados em tempo real.
*   **Detalhes:** Veja informações específicas de cada livro por ID.
*   **Edição:** Altere dados de livros já cadastrados.
*   **Exclusão:** Remova registros do sistema com apenas um clique.

## 🛠️ Tecnologias Utilizadas
*   **Linguagem:** JavaScript (Node.js)
*   **Framework Web:** Express
*   **Banco de Dados:** MySQL (utilizando Pool de Conexão)
*   **Template Engine:** Handlebars (HBS)
*   **Ferramentas Auxiliares:** `nodemon` (auto-reload) e driver `mysql2`.

## 📋 Pré-requisitos
Antes de começar, você vai precisar ter instalado em sua máquina:
* [Node.js](https://nodejs.org)
* [MySQL](https://www.mysql.com) (ou um ambiente como XAMPP/WAMP)
